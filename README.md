# My Vibe Coded ~~Trash Bin~~ Tool Box

This project consists of some useful (at least to me) vibe-coded tools. Most of the HTML, CSS and JavaScript files are written by free tier LLM.

All tools are static web pages.

## List of Tools

- Hacker News: Retrieves and displays the latest stories from Hacker News using the [Hacker News API](https://hacker-news.firebaseio.com/v0/topstories.json). Sometimes it is faster than visiting the HN site. 
- Media Player: A media player on a static web page. It (only) supports playing files uploaded by the user.
- Podcast Viewer: Search podcasts (using iTunes search API) and list episodes with download links.
- Relic Interpreter: An old version of [Relic](https://github.com/heanyang1/relic) rewritten in TypeScript.
- Wang Tiler: A replica of [Cat's Eye Wang Tiler](https://catseye.tc/article/Automata.md#backtracking-wang-tiler) that generates [Wang tiles](https://en.wikipedia.org/wiki/Wang_tile).
- Matrix Visualizer: A visualizer made for [this blog post](https://heanyang1.github.io/myblog/2026/03/14/wave-function-collapse-algorithm-in-j.html).
- Clipboard Tool: Type something and copy it. This is a workaround for the programs that doesn't support input method in my system.
